# Smart Bead Pattern V1

这是现有图片转拼豆链路上的可关闭规则层，不替换原有像素化、色卡、统计或导出逻辑。

## 链路

原图 -> 现有像素化与真实色卡映射 -> Smart Bead V1（可选） -> 现有 `optimizeGrid` -> 统计与导出。

V1 当前包含：

- 人像模式的软肤色提亮，仅对暖色、非极暗且具有肤色倾向的格子处理；
- 基于相邻颜色差异的结构重要性计算；
- 受结构重要性和细节保留参数约束的小连通区域净化；
- 标准、人像、Q版三套规则参数；
- 小、中、大图纸尺寸的参数微调；
- 任意异常自动保留旧链路结果。

模块文件：`smart-bead-v1.js`。

## 功能开关

前端“拼豆优化（规则 V1）”默认开启，但可随时关闭。关闭时生成结果与现有链路一致。

## 限制

V1 不包含 MediaPipe、SAM、OCR 或生成式模型，不识别身份，不上传原图，也不会改变现有色卡数据。
