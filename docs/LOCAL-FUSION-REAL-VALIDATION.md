# 本地融合：实图与性能验证

2026-10-14。结论：采样接缝可用，预算阶段重复分配已优化并保持测试结果；自动分类与完整生产验收仍未通过，暂不统一默认入口、删除左栏或上线。

## 实图结果

使用当前磁盘上的贺岁牌 PNG、品牌标识、既有幻想插画，输入文件哈希和尺寸见 manifest。幻想插画不当作真实人像照片。MARD_FULL_COLORS 实际 291 色，目标 16 色，保持源图比例、不裁剪、不自动去背景。三个输入、52/104 两档、V2.5/自动融合/六手动采样，共 48 项。

- 48 项均无色卡外颜色。
- 自动融合 6/6 保守回退，色号/RGB 与 V2.5 为零格差异，不能称为自动融合画质提升。
- 贺岁牌路由 auto、置信度约 0.054；实际品牌 Logo 被路由为 illustration、置信度 1；幻想插画被路由为 photo、置信度约 0.381。这些是分类器输出，不是对素材语义的确认。
- 手动 dominant 的 Logo 色块较整齐，但并非所有素材都更好；SSIM、DPID 等存在显著明暗/边缘差异，不能全局指定一种策略。
- 缺核实的真实照片和动漫输入；未用程序生成图片冒充这些类别。未测浏览器与 native canvas 的 ICC 一致性。

## 本次修复

1. 自动融合只计算一次源分类证据，手动策略复用 pipeline 的分析，避免重复分析。新增实际分类器接线测试验证 eligible pixel 与低置信 hard-logo 回退；这些是算法夹具，不替代实图质量验收。
2. 预算分支原先每次找合色目标都 `grid.flat()`，在大量改色时反复分配整图数组。现在预算阶段只展平一次，继续按同样的行序动态 `.find()`。`applyBudgetPlan` 原地改 cell、不替换 cell，因此保留原有 first-match 和 name/hex 传播行为，没有改预算策略。

48 份完整 grid SHA256 在优化前后全部一致，包含附带信息，不仅是色数相同。专项测试另覆盖链式计划与可选 name/hex 的动态查找；独立源码复核未发现阻断问题。仍有线性查找，不宣称所有瓶颈已消除。

## Node 性能

同一贺岁牌，三次顺序采样，未预热，P95 为三次最大值。下表是 P50 秒数；这些不是浏览器操作耗时。500 为保持比例的 333×500，不是 500×500。

| 长边 | V2.5 前→后 | 自动融合 前→后 | 手动 dominant 前→后 |
|---|---:|---:|---:|
| 52 | 3.47→2.56 | 3.17→2.39 | 3.35→2.42 |
| 78 | 4.34→2.57 | 4.44→2.80 | 3.69→2.56 |
| 104 | 3.92→3.08 | 3.58→2.92 | 3.05→2.71 |
| 250 | 8.76→4.38 | 9.64→4.59 | 6.04→4.27 |
| 500 | 39.12→10.50 | 41.48→11.82 | 29.36→9.44 |

两轮各 45 次，共 90 次性能计算；GC/运行环境有波动，不把倍率当稳定承诺。原始 P50/P95/每次样本均已保存。优化前后进程 RSS 采样最大分别约 616.4/666.4 MiB，后者未降低；这是运行前/后采样，不是真实峰值，不能称为内存优化通过。

## 回归与边界

- 相关最终回归 260/260 PASS，日志 `/tmp/libms-fusion-real-final-regression.tap`。
- 融合关闭时，52/78/104/250/500 的合成输入默认矩阵仍与原 pipeline 相同；实图预算优化以另外 48 份完整哈希比较验证。
- 未改布局、工具栏、色块条、工程/导出格式、API、发布配置，不提交混合 dirty 工作树、不上线。唯一影响现有生产计算的修改是保留结果的预算重复分配优化。
- 当前没有新“融合”按钮，也未设为默认引擎。尚不能认定完整三引擎融合成品；旧版独有算法未硬塞进链路。

## 产物与复现

- `local-fusion-validation/`：优化前质量、性能、manifest、对照图、浏览器前样本。
- `local-fusion-validation-optimized/`：优化后质量、性能、完整哈希比较、浏览器后样本和截图。
- `tools/local-fusion-validation.mjs` 支持 `--out=docs/目录`、`--quality-only`、`--performance-only`、`--compare=docs/目录`。依赖本机捆绑 @napi-rs/canvas。
- 优化前完整引擎备份 `/tmp/libms-fusion-before-budget-flat-cache.mjs`，原始数字不可在新代码下假称重现。重跑请写入新目录，避免覆盖既有证据。
