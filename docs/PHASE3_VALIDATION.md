# Phase 3 验证与交接（2026-09-16）

## 范围

本轮只改编辑工作台和渲染/缩放层。生成算法及 Region-Aware Pipeline 未改；旧画板保留为高级工具兼容入口。根目录与 `deploy/` 的运行代码已同步。

## 数据与编辑

- 唯一已提交图纸事实源仍是 `app.js` 的 `state.grid`（Color Grid）。新工作台经 `LibmsWorkspaceBridge.applyCellChanges()` 直接编辑它，统计、跟做和导出随之读取同一矩阵。
- `services/editor-service.js` 支持单豆换色、全局换色、选区换色、Undo、Redo；历史记录只保存受影响豆子的前后色，最多 100 步，新编辑清空 Redo。
- 旧画板仍以 `state.editorGrid` 临时副本工作，保存后写回 `state.grid`。在旧画板保存时，新工作台历史清零，避免跨两套历史执行错误的 Undo。
- 已编辑图纸重新生成/换图需在新工作台确认覆盖；未确认的旧入口会被生成/上传守卫拒绝。

## 画布与 Zoom

- Original、Blocks、Beads、Pattern 为同一结果的视图，不在视图切换时重新生成。Base/Grid/Codes/Overlay 四层 Canvas 按设备像素比绘制，色号不经低分辨率 PNG 的 CSS 缩放。
- 缩放按钮、可输入百分比、滑块、Fit、100%、鼠标滚轮共享 `viewport-service` 的 Zoom 状态；滚轮围绕指针所在豆子缩放。画布拖动使用指针捕获，支持移动工具/空格/中键。
- 色号层与预览图导出的色号设置彼此独立；预览默认无色号，图纸导出保留网格、坐标、色号设置。

## 已知边界

- 旧画板的高级工具仍使用自己的临时副本及旧 Undo，尚未迁入新编辑服务。
- 当前没有自动化浏览器 Runner；浏览器项目验收为人工操作和冻结矩阵快照测试。未检查下载文件字节，仅检查实际交给导出渲染器的矩阵与参数。
- 浏览器刷新后手动编辑不会自动恢复为可编辑项目；版本化 Project JSON 属于后续阶段，本轮不扩展。
- 最新 Cell 20 下 104×98 Fit/色号在 100% 的视觉和耗时还需用户本地确认。
