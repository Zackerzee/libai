# Phase 3 预检

## 现有事实

- 最终生成矩阵是 `app.js` 内的 `state.grid`；预览和导出读取它。旧画板在 `openEditor()` 时通过 `cloneGrid(state.grid)` 创建 `state.editorGrid`，保存时才写回，因此旧画板与工作台之间存在临时副本。
- 旧画板的画笔与全局换色分别使用 `paintUndo`、`replaceUndo`，尚无统一 Redo；工作台只有视图状态，没有可选择的真实单豆编辑。
- 工作台当前用一张低分辨率 PNG 的 CSS `scale()` 做 Zoom；低分辨率文字一起放大时会模糊，Zoom 也未围绕鼠标位置。
- 原有 `processImage()` 有并发守卫 `isProcessingImage`，上传后的自动预览与显式生成仍需要针对相同输入连续三次复测。初次生成与改宽后重生成曾观察到少量矩阵差异；此问题不通过修改算法掩盖。

## Phase 2 人工验收状态

已核对：图片上传并生成、四视图入口、缩放/平移入口、色号与导出设置隔离、跟做入口、编辑器入口。旧画板“连续换五颗豆→撤销→重新生成”端到端尚未可靠验完；现有副本架构使其不能作为新工作台唯一编辑事实源。

## 处理顺序

先接入直接修改 `state.grid` 的编辑适配和最小 diff 历史，再实现共享坐标的 HiDPI 分层渲染及统一 Zoom。旧画板保留为其他高级工具的兼容入口，不在本轮删除。
